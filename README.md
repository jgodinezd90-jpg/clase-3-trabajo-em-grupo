# Inventario de Tienda

- Estudiante: José Godinez
- Curso: ISB-08 Organización de Archivos y Estructura de Datos – UISIL
- Proyecto elegido: Opción 1 – Inventario de tienda
- Lenguaje: C#

# Requisitos

- Windows 10 u 11
- Visual Studio 2022 o superior
- .NET 8 SDK

# Funciones

- Registrar, modificar y eliminar productos.
- Buscar por nombre o código (filtro en vivo).
- Ordenar por nombre o precio.
- Registrar entradas y salidas de mercadería.
- Ver, buscar y eliminar movimientos del historial.
- Validaciones: campos obligatorios, precio inválido, código repetido, salida mayor a la existencia y operaciones con estructuras vacías.


# Estructura de archivos

- `Program.cs` – punto de entrada.
- `Modelos.cs` – clases `Producto` y `Movimiento`.
- `ListaMovimientos.cs` – nodo y lista enlazada propia.
- `FormPrincipal.cs` – interfaz y lógica.
